# Data-Cleaning-Project
Data Cleaning and Visualization using Python

## Project Objective
This project focuses on cleaning raw data and visualizing insights using Python libraries.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Streamlit

## Features
- Handling missing values
- Removing duplicates
- Detecting and removing outliers
- Data visualization using charts and graphs
- Dashboard creation using Streamlit

## Dataset Used
Titanic Dataset

## How to Run

Install required libraries:

pip install pandas matplotlib seaborn streamlit numpy

Run the project:

streamlit run datacleaning.py

Project completed successfully.
